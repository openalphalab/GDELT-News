Sizes use bytes; decimal MB is bytes / 1,000,000. Token counts are actual local
`tiktoken` 0.12.0 `o200k_base` counts for literal file text, excluding chat framing.
They are not a promise about another model's tokenizer. Compression times are
single in-memory runs on this host, excluding file I/O; no statistical latency
claim is made. JSONL versus packed JSON uses about 9.4% fewer tokens in packed
form, with 2,215 unique bodies and all 2,359 observation records preserved.

For routine retrieval or batched LLM processing, use the readable JSONL records
and retain their metadata header. Zstandard level 3 was fastest among the tested
compression settings; level 9 gives a useful size/speed tradeoff. Brotli 11 was
the smallest tested setting but much slower to create. Decompress before
sending text to a model; smaller compressed bytes do not reduce input tokens.
Choose a batch size from the actual target model's available context.
